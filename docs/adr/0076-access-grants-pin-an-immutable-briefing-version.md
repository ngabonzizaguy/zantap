# Access grants pin an immutable Briefing version

Ops edits ZanTap Briefing through a structured draft and deliberately publishes
an immutable Briefing version. Every new Access grant pins the version current
at creation; later publications do not silently change the claims, evidence,
media, or documentation an active recipient sees. Ops may explicitly migrate a
grant or issue a replacement. This consumes more stored snapshots and requires
intentional updates, but preserves exactly what a stakeholder acknowledged and
reviewed and makes follow-up/audit history trustworthy.
