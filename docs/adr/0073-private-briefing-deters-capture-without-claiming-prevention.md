# Private briefing deters capture without claiming prevention

The private presentation will discourage and attribute unauthorized capture,
but will not claim that a website can prevent screenshots. It combines
recipient-attributable watermarking, confidentiality acknowledgement,
search-engine exclusion, private/no-store responses, protected media delivery,
and removal of print/download affordances. It deliberately avoids blocking
right-click, text selection, and common keyboard shortcuts because those
controls are easily bypassed, impair accessibility, and still cannot stop OS
screenshots, cameras, external capture devices, or a determined viewer.
