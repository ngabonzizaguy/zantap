# Briefing activity excludes invasive session surveillance

Ops may inspect purposeful Briefing activity: successful/failed unlocks,
Viewing-session start/last-seen/end, furthest chapter reached, evidence panels
opened, Operator grant/share actions, and Briefing-interest submission, plus
coarse device/browser data and a privacy-preserving network fingerprint for
abuse investigation. ZanTap will not capture keystrokes, cursor replay, screen
recordings, invasive heatmaps, or unsent form text. The narrower record gives
Operators enough follow-up and security context while avoiding disproportionate
surveillance of invited stakeholders.
